# 海π数学节提交清单

## 文件夹命名

按通知要求，每项成果单独放入文件夹。文件夹名称格式：

```text
学校-数学工程创意实践类-学段-学生姓名
```

示例：

```text
XX中学-数学工程创意实践类-初中组-李明
```

## 必交材料

- 成果主件：可运行程序文件、部署链接或可打开的网页构建文件。
- 作品说明文档：可基于 `docs/submission/作品说明.md` 整理为 Word 或 PDF。
- 学生作品原创性与 AI 规范使用声明：使用主办方附件 1 模板填写。
- 学校成果汇总表：使用主办方附件 2 模板填写。

## 建议支撑材料

- 3 到 5 张程序运行截图，文件名写清对应实验内容。
- 3 分钟以内 MP4 展示视频，展示参数设置、图形放置、运行和 CSV 导出。
- 至少一份程序导出的 CSV 实验数据。
- 如提交部署链接，同时保留离线构建文件，避免评审时链接不可访问。

## 提交前检查

- 程序能在普通浏览器中打开并运行。
- 页面打开后会自动运行“滑翔机发射器”案例，代数会增长，最上方显示截图风格的动态讲解展板。
- 首次打开页面会弹出演示引导框，点击“开始演示”会进入 Show Mode。
- 点击“暂不演示”后，引导框关闭，标题旁“开始演示”按钮会短暂高亮提示入口位置。
- 标题旁始终有醒目的“开始演示”按钮，可随时重新启动演示。
- 桌面宽屏首屏以大画布为主，实时数据证明位于实验场景下方，不挤占画布空间。
- 画布旁边能直接看到开始/暂停、停止/重置、恢复本案例、单步、随机、清空按钮，不需要滚动到参数区才能运行。
- 画布旁显示当前场景、推荐注入、改变变量、预期观察和 `X'_t = X_t + P` 的数学表达。
- 右侧栏目顺序为实验场景、实时数据证明、演示进度、注入工具与参数，并与左侧顶部对齐。
- 移动端顺序为标题/演示按钮、动态讲解展板、画布、实验场景、数据证明与控制、底部长文档，页面不横向溢出。
- 实验场景区显示约 20 个紧凑瓷砖卡片，动画丰富案例排在前面，不需要先选择分类 Tab。
- 每张实验场景卡片显示场景名称、现象类型、推荐注入元素和点击观察任务。
- 点击任意实验场景卡片一次，就能立即切换并自动运行对应实验，同时把注入图形切到推荐工具。
- 飞船赛道、多振子剧场、密度三连、橡果长跑、稳定小方块等代表性案例都能正确加载并自动运行。
- 点击“开始演示”后，程序能自动播放约 3 分钟、6 段精华代表性实验。
- 演示模式的“暂停演示”“下一段”“退出演示”都能正常工作。
- 最后一段完成后，程序保持“总结观察”持续运行，直到评委点击“退出演示”。
- 顶部动态讲解展板能同步显示当前实验、实时结论、规则机器 T、当前代数、活细胞、出生和死亡。
- 顶部六年级规则卡能清楚显示 `先数 n`、`n < 2`、`n = 2`、`n = 3`、`n > 3` 和 `下一张图 = T(这一张图)`。
- 页面底部默认展开长篇文档式解释，包含项目是什么、规则机器、不是视频、实验场景墙、数据曲线和数学结论六节。
- 底部进阶数学说明能显示 KaTeX 公式，包含 \(x_t(r,c)\)、\(n_t(r,c)\)、\(X_{t+1}=T(X_t)\) 和 \(X_t=T^t(X_0)\)。
- 公式渲染失败时仍有纯文字 fallback，不会出现空白公式区。
- 顶部小卡片同时包含“小学生版”“算子怎样生成图像”“这像一场局部博弈”“进阶公式”四块内容。
- 点击约 20 个实验场景后，顶部说明和底部当前案例提示会同步变成固定点、周期轨道、移动涌现、初始条件敏感或长期变化等对应解释。
- 小屏幕下公式不会撑破页面，正文不横向溢出。
- 约 20 个实验场景覆盖持续创造、长期变化、飞船赛道、滑翔机移动、周期振子、密度差异、随机重组、固定点等主要情况。
- 点击实验场景后，注入工具与参数区的棋盘、推荐注入图形、场景、种子、密度、速度会和当前场景对应。
- “当前实验”参数摘要能明确显示场景名称、棋盘、图形/场景、推荐注入、种子、密度、速度和是否自动运行。
- “密度改变命运”会自动轮换稀疏、中等、拥挤三种初始条件，统计曲线和出生/死亡数字会跟随变化。
- 先点“脉冲星花瓣”再点“拥挤爆发”时，注入图形下拉框会从“滑翔机”切到“稳定小方块”，不会错误停留在上一个场景的工具。
- 开始、暂停、继续、停止/重置、恢复本案例的状态文案清楚。
- `停止/重置` 会回到最近一次手绘或注入后的扰动起点；`恢复本案例` 会清除扰动并回到当前实验场景原始配置。
- 暂停或停止时点击画布会保存成新的手绘第 0 代，点击“开始”会从这张手绘图继续计算。
- 单独放入一个孤立点后点击“开始”，该点下一代按 `n < 2` 规则消失，并且界面解释这是数学规则导致的结果。
- 手动画出三连点后点击“开始”，图形会继续按生命游戏规则演化，而不是恢复旧案例。
- 在“滑翔机发射器”中点击画布会注入稳定小方块，后续滑翔机路径或碰撞区域会发生变化，当前场景仍保持选中。
- 在“脉冲星花瓣”中点击画布会注入滑翔机，顶部说明会显示周期系统被外来移动结构扰动。
- 在“密度三连”中点击画布会注入稳定小岛，自动轮换停止在扰动后的当前棋盘，当前场景仍保持选中。
- 运行中点击画布会实时注入细胞或当前选择的图形，程序继续运行且说明文字提示这是实时扰动。
- 注入后点击“停止/重置”，棋盘会回到扰动后的起点，而不是回到注入前的旧案例。
- 运行中修改棋盘、种子或密度，会立即停止旧状态并加载新的第 0 代；修改注入图形只改变下一次点击要加入的元素。
- 清空后不会自动恢复旧图形；再点案例、随机或图形可以正常重新开始。
- 界面主色已经调整为深蓝 + 琥珀，桌面和移动端文字不遮挡、不溢出。
- 稳定小方块、闪烁灯、滑翔机、三种飞船、橡果和滑翔机发射器都能放置。
- 注入图形下拉框选择后，棋盘不会被重置；下一次点击画布时会注入该图形。
- “稀疏种子”“拥挤开始”“飞船家族”“图形花园”“长期变化”等场景选择后会立即切换。
- 清空后显示空棋盘状态，提示通过案例、随机或图形重新开始。
- 实时中文解释能随着代数变化和画布注入更新，并明确说明这是数学公式逐代计算，不是视频。
- 开始、暂停、单步、随机、清空和 CSV 导出功能正常。
- 作品说明中的实验数据来自真实运行记录。
- 引用资料已经在作品说明中列出。
- 原创性与 AI 规范使用声明已经按官方模板填写。
- 以学校为单位在 2026-05-21 17:30 前提交到通知指定邮箱。
