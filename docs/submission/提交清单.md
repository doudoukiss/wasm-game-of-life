# 海π数学节提交清单

## 文件夹命名

按通知要求，每项成果单独放入文件夹。文件夹名称格式：

```text
学校-数学工程创意实践类-学段-学生姓名
```

示例：

```text
XX中学-数学工程创意实践类-初中组-李明
```

## 必交材料

- 成果主件：部署链接或 `主版本-dist/` 静态站点文件。
- 离线备用入口：`离线备用版/生命演化数学游戏-离线版.html`，用于无法联网、无法安装环境或 WebAssembly 受限的电脑。
- 作品说明文档：可基于 `docs/submission/作品说明.md` 整理为 Word 或 PDF。
- 运行说明文档：可直接使用 `docs/submission/运行说明.md` 或打包后生成的 `先打开我-运行说明.md`。
- 学生作品原创性与 AI 规范使用声明：使用主办方附件 1 模板填写。
- 学校成果汇总表：使用主办方附件 2 模板填写。

## 建议支撑材料

- 3 到 5 张程序截图，文件名写清对应玩法场景，例如“发射器投放障碍物”“脉冲星被滑翔机扰动”。
- 3 分钟以内 MP4 玩法视频，重点展示选择关卡、投放道具、点击画布、暂停观察、阅读数学旁白。
- 至少一份程序导出的 CSV 生命数据，说明数据来自真实运行。
- 如提交部署链接，同时保留离线构建文件和离线 HTML 备用版，避免现场网络不可用影响展示。

## 建议提交包结构

```text
生命演化数学游戏/
├── 先打开我-运行说明.md
├── 主版本-dist/
├── 离线备用版/
```

可在项目根目录运行以下命令生成上述目录：

```bash
npm run package:submission
```

## 提交前检查

- 页面标题和文档统一使用 `生命演化数学游戏`，定位是互动教学游戏，不是单纯技术演示。
- 主版本通过部署链接、`npm run preview` 或静态文件服务器打开；不要把双击 `dist/index.html` 作为唯一运行方式。
- 离线备用 HTML 可以直接双击打开，不需要 Node.js、Rust、WebAssembly 或网络。
- `先打开我-运行说明.md` 写清楚打开顺序：主版本 -> 离线备用版 -> 视频/截图/CSV。
- 页面打开后无阻塞弹窗，默认直接运行“滑翔机发射器”关卡。
- 首屏画布是视觉中心，无需滚动就能看到动态岛道具栏、关卡、播放/暂停、单步、重置、恢复本关、清空和紧凑生命数据。
- `1 选道具 · 2 选关卡 · 3 点画布改变系统` 步骤条明显可见，不再使用旧的准备区标题。
- 画布旁任务明确提示：点击棋盘投放推荐道具，观察规则机器如何重新计算。
- 常用投放道具包含稳定小方块、滑翔机、闪烁灯、飞船和单格，按钮图标直接显示对应生命图形；更多复杂图形通过关卡和场景组合展示。
- 鼠标悬停棋盘时能看到当前投放道具预览，预览形状与单格、稳定小方块、滑翔机、闪烁灯、飞船一致。
- 点击棋盘后有清楚但不遮挡的琥珀色投放反馈；运行中显示实时扰动，暂停或停止时显示新起点。
- 点击任意关卡一次，即可切换、同步推荐道具、清空旧曲线并自动运行。
- 动画冲击力强的关卡排在前面：滑翔机发射器、长期变化、飞船赛道、滑翔机移动、脉冲星花瓣、多振子剧场、密度三连、橡果长跑。
- 运行中点击画布会实时投放道具，程序继续运行，右侧说明这是改变当前图像 \(X_t\)。
- 暂停或停止时点击画布会改变第 0 代起点，点击开始后从手绘或投放后的棋盘继续计算。
- 单独投放一个孤立单格后，下一代可能按 \(n<2\) 规则消失，界面应解释这是数学规则导致的结果。
- 修改棋盘、密度、种子、关卡/场景或随机起点后，默认投放道具回到“障碍块”；只调整速度时不改变当前道具。
- `停止/重置` 回到最近一次投放后的起点；`恢复本关` 清除扰动并回到当前关卡原始配置。
- 清空后不会自动恢复旧图形；再点关卡、随机或居中投放可以正常重新开始。
- 右侧上方是紧凑 `进阶自定义`，包含棋盘、场景、种子、密度、速度、重开起点、居中投放和导出曲线 CSV。
- 右侧中部是 `生命数据` 曲线和趋势标签；代数、活细胞、占比、出现、消失继续在关卡控制区显示。
- 右侧下方是 `互动证明 / 数学旁白`，按“刚刚发生 / 规则分类讨论 / 为什么道具会改变动画 / 接下来观察”解释当前操作。
- 规则段能清楚解释 `n=0或1`、`n=2`、`n=3`、`n=4到8`，并说明道具改变局部 `n` 后会改变碰撞、移动、周期或稳定结果。
- 改棋盘、密度、种子、速度或投放道具时，画布上会出现不遮挡操作的弹幕反馈，并说明 `X_0`、`X_t`、速度或局部 `n` 被怎样改变。
- 玩法演示按钮在标题旁，演示进度和暂停/下一步/退出是迷你状态，不占用右侧大块空间。
- 玩法演示约 2 分钟内覆盖发射器碰撞、飞船移动、周期扰动、密度切换和长期变化；暂停、下一步、退出都能正常工作。
- 画布正下方默认展开 `4 看懂演化：同一规则怎样长出不同图像`，包含算法分类规则、投放道具演化和关卡演化。
- 画布下方演化模块使用小棋盘、小曲线和微动画说明固定点、周期、移动、长期变化和起点敏感性；底部说明区不再重复这一模块。
- 页面底部默认展开玩法与规则说明，包含规则机器、为什么不是视频、数据曲线怎样读、数学结论和进阶公式。
- 底部进阶公式能显示 KaTeX；公式失败时有纯文字 fallback，不出现空白区。
- 简单规则说明能清楚表达：先数周围 8 格邻居，太孤单消失，刚好留下或出现，太拥挤消失。
- 关卡与道具语言统一，不再把主体验割裂成“精选案例”和“自由探索”。
- 完整解释区不再重复放参数设置面板，也不重复画布下方演化模块，只保留玩法与规则说明、数据曲线读法和进阶公式。
- CSV 导出保留为报告导出工具，不作为主玩法入口。
- 桌面端画布、关卡条、道具栏和右侧旁白对齐；移动端无横向溢出，按钮文字不挤压。
- 飞船赛道、多振子剧场、密度三连、橡果长跑、稳定小方块等代表性关卡都能正确加载。
- 先点“脉冲星花瓣”再点“拥挤爆发”时，推荐投放道具和参数摘要同步改变，不保留上一个关卡的错误工具。
- 开始、暂停、继续、停止/重置、恢复本关、清空、随机和 CSV 导出功能正常。
- 文档中的玩法视频脚本、截图建议和说明文字都以“教学游戏”为核心定位。
- 原创性与 AI 规范使用声明已经按官方模板填写。
- 以学校为单位在 2026-05-21 17:30 前提交到通知指定邮箱。
