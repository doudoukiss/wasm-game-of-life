# 海π数学节提交清单

## 文件夹命名

按通知要求，每项成果单独放入文件夹。文件夹名称格式：

```text
学校-数学工程创意实践类-学段-学生姓名
```

示例：

```text
XX中学-数学工程创意实践类-初中组-李明
```

## 必交材料

- 成果主件：可运行程序文件、部署链接或可打开的网页构建文件。
- 作品说明文档：可基于 `docs/submission/作品说明.md` 整理为 Word 或 PDF。
- 学生作品原创性与 AI 规范使用声明：使用主办方附件 1 模板填写。
- 学校成果汇总表：使用主办方附件 2 模板填写。

## 建议支撑材料

- 3 到 5 张程序运行截图，文件名写清对应实验内容。
- 3 分钟以内 MP4 展示视频，展示参数设置、图形放置、运行和 CSV 导出。
- 至少一份程序导出的 CSV 实验数据。
- 如提交部署链接，同时保留离线构建文件，避免评审时链接不可访问。

## 提交前检查

- 程序能在普通浏览器中打开并运行。
- 页面打开后会自动运行“规则不是视频”案例，代数会增长，顶部横幅显示公式和变量。
- 首次打开页面会弹出演示引导框，点击“开始演示”会进入 Show Mode。
- 点击“暂不演示”后，引导框关闭，标题旁“开始演示”按钮会短暂高亮提示入口位置。
- 标题旁始终有醒目的“开始演示”按钮，可随时重新启动演示。
- 桌面宽屏首屏以大画布为主，实时数据证明位于精选案例下方，不挤占画布空间。
- 右侧栏目顺序为精选案例、实时数据证明、演示进度、自由探索，并与左侧顶部对齐。
- 移动端顺序为标题/演示按钮、讲解横幅、画布、精选案例、数据证明与控制，页面不横向溢出。
- 精选案例区显示 6 个瓷砖卡片，不需要先选择分类 Tab。
- 点击任意精选案例卡片一次，就能立即切换并自动运行对应实验。
- 点击“开始演示”后，程序能自动播放约 3 分钟、6 段精华代表性实验。
- 演示模式的“暂停演示”“下一段”“退出演示”都能正常工作。
- 最后一段完成后，程序保持“总结观察”持续运行，直到评委点击“退出演示”。
- 画布上方讲解横幅能同步显示主结论、公式 B3/S23、变量 n/state/t、算法逻辑和结果意义。
- 画布下方“数学算子说明”能显示 KaTeX 公式，包含 \(x_t(r,c)\)、\(n_t(r,c)\)、\(X_{t+1}=T(X_t)\) 和 \(X_t=T^t(X_0)\)。
- 公式渲染失败时仍有纯文字 fallback，不会出现空白公式区。
- 算子说明同时包含“小学生版”“公式版”“算子怎样生成图像”“这像一场局部博弈”四块内容。
- 点击 6 个精选案例后，算子说明会同步变成固定点、周期轨道、移动涌现、初始条件敏感或长期变化等对应解释。
- 小屏幕下公式不会撑破页面，正文不横向溢出。
- 6 个精选案例分别覆盖规则不是视频、稳定结构、周期之美、局部规则产生移动、密度改变命运、复杂持续创造。
- 点击案例导航后，自由探索区的棋盘、图形/场景、种子、密度、速度会和当前案例对应。
- “当前案例参数”能明确显示案例名称、棋盘、图形/场景、种子、密度、速度和是否自动运行。
- “密度改变命运”会自动轮换稀疏、中等、拥挤三种初始条件，统计曲线和出生/死亡数字会跟随变化。
- 先点“脉冲星”再点“拥挤开始”时，图形下拉框会回到“单格”，不会错误停留在“脉冲星”。
- 开始、暂停、继续、停止/重置的状态文案清楚，停止/重置会回到当前实验第 0 代。
- 运行中修改棋盘、图形、种子或密度，会立即停止旧状态并加载新的第 0 代。
- 清空后不会自动恢复旧图形；再点案例、随机或图形可以正常重新开始。
- 界面主色已经调整为深蓝 + 琥珀，桌面和移动端文字不遮挡、不溢出。
- 稳定小方块、闪烁灯、滑翔机、三种飞船、橡果和滑翔机发射器都能放置。
- 图形下拉框选择后，棋盘会立即显示对应图形。
- “稀疏种子”“拥挤开始”“飞船家族”“图形花园”“长期变化”等场景选择后会立即切换。
- 清空后显示空棋盘状态，提示通过案例、随机或图形重新开始。
- 实时中文解释能随着代数变化更新，并明确说明这是数学公式逐代计算，不是视频。
- 开始、暂停、单步、随机、清空和 CSV 导出功能正常。
- 作品说明中的实验数据来自真实运行记录。
- 引用资料已经在作品说明中列出。
- 原创性与 AI 规范使用声明已经按官方模板填写。
- 以学校为单位在 2026-05-21 17:30 前提交到通知指定邮箱。
