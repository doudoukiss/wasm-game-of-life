# 生命演化数学实验室作品说明

## 创意来源

本作品来源于康威生命游戏。它把生命现象抽象为一个二维网格：每个格子只有“活”或“死”两种状态，每一代都根据周围 8 个邻居的数量决定下一代状态。作品希望用可操作的互动程序展示一个数学现象：非常简单的局部规则，也能产生稳定结构、周期振荡、移动图形和复杂群体变化。

## 数学原理

本作品把整张棋盘看成一幅由 0 和 1 组成的图像。第 \(t\) 代图像记作 \(X_t\)，第 \(r,c\) 个格子的状态记作：

\[
x_t(r,c)\in\{0,1\}
\]

其中 1 表示活细胞，0 表示死细胞。每个格子先计算周围 8 个邻居中有多少活细胞：

\[
n_t(r,c)=\sum_{i=-1}^{1}\sum_{j=-1}^{1}x_t(r+i,c+j)-x_t(r,c)
\]

生命游戏的核心可以写成一个算子 \(T\)：

\[
X_{t+1}=T(X_t),\qquad X_t=T^t(X_0)
\]

这句话的意思是：第 \(t+1\) 张图像不是提前画好的，也不是视频播放出来的，而是同一台“数学机器” \(T\) 对第 \(t\) 张图像重新计算得到的。第 \(t\) 代图像就是从初始图像 \(X_0\) 出发，把同一个算子连续使用 \(t\) 次。

每个细胞的下一代状态由邻居数量决定：

- 活细胞邻居少于 2 个时死亡，表示数量不足。
- 活细胞邻居为 2 或 3 个时继续存活。
- 活细胞邻居多于 3 个时死亡，表示过度拥挤。
- 死细胞邻居正好为 3 个时变为活细胞。

用小学生能理解的话说：每个小格子每一轮只看身边 8 个朋友。朋友太少会孤单，朋友太多会拥挤，刚好合适就能留下；如果一个空格子周围正好有 3 个朋友，它就会诞生新细胞。所有格子同时判断，所以不会出现“先动的格子影响后动的格子”的情况。

这个规则也可以理解成一场局部博弈：每个细胞都只和邻近 8 个位置发生关系，在“孤单、拥挤、刚好合作”的规则里决定下一轮命运。没有导演，没有预设路线，整体图案是由许多局部判断共同生成的。

程序把网格看成首尾相接的环面，边缘格子也能计算完整的 8 个邻居。实验面板记录每一代的活细胞数量、活细胞占比、出生数和死亡数，并绘制活细胞数量曲线。通过这些数据，可以比较不同初始密度、不同图形和不同随机种子下的演化差异。

不同现象可以用同一个算子语言解释：

| 现象 | 数学表达 | 直观解释 |
| --- | --- | --- |
| 稳定结构 | \(T(X)=X\) | 算完以后图像不变，说明进入固定点。 |
| 周期结构 | \(T^k(X)=X\) | 图像没有静止，但每隔 \(k\) 代回到原样。 |
| 移动结构 | \(T^k(X)\) 是平移后的 \(X\) | 代码没有写“向前飞”，整体移动从局部规则中涌现。 |
| 密度差异 | 同一 \(T\)，不同 \(X_0\) | 起点不同，活细胞曲线和最终结局可能不同。 |
| 长期复杂 | 多代后仍有出生和死亡 | 系统不快速收敛，简单规则能持续创造新结构。 |

## 实现过程

核心计算使用 Rust 编写，并通过 WebAssembly 在浏览器中运行。Rust 负责保存棋盘状态、执行生命游戏规则、放置典型图形、生成可复现实验初始状态，并输出统计数据。浏览器端使用 Vite 和原生 Canvas 绘制棋盘与折线图，打开页面后会自动运行“规则不是视频”精选案例，并弹出演示引导框，建议评委先看约 3 分钟精华评审演示。界面把主视觉空间优先留给演化画布，把代数、活细胞、占比、出生、死亡和活细胞曲线放在右侧精选案例下方作为数据证明。界面还提供一键精选案例瓷砖、当前案例参数摘要、开始、暂停、继续、停止/重置、单步、随机、清空、图形放置和 CSV 导出功能。

程序支持五种典型图形：

- `block`：稳定结构，用于观察不变性。
- `blinker`：周期为 2 的振荡结构。
- `toad`、`beacon`、`pulsar`、`pentadecathlon`：不同大小、不同周期的振荡结构。
- `glider`：会移动的轻量结构，用于观察局部规则形成整体迁移。
- `lwss`、`mwss`、`hwss`：轻型、中型、重型飞船，大小和移动外形不同。
- `acorn`：初始很小但会变化很久的结构。
- `glider_gun`：滑翔机发射器，会持续产生新的滑翔机。

界面还提供“演示模式”“精选案例”和“实验场景”选择。页面默认入口是“规则不是视频”：中央 3 个细胞横竖切换，帮助评委马上理解画面不是视频，而是每一代重新“数邻居、套公式、生成下一代”的计算结果。画布上方的大横幅不再只是说明书文字，而是用展板结构同步显示主结论、公式 `B3/S23`、核心变量 `n = 周围 8 格活邻居数量`、`state = 当前生死状态`、`t = 当前代数`，以及当前结果为什么有数学意义。画布下方新增 KaTeX 公式卡和“数学算子说明”，用四种层次解释同一件事：小学生版说明朋友太少或太多会死亡，公式版说明 B3/S23，算子版说明 \(X_{t+1}=T(X_t)\)，局部博弈版说明整体图案来自许多局部生存判断。标题旁保留醒目的“开始演示”按钮；如果评委关闭首次演示引导，按钮会短暂高亮，提示可以从这里重新进入演示。右侧“实时数据证明”区域突出显示代数、活细胞数量、占比、出生数、死亡数和人口曲线，让观众看到视觉变化背后有可记录、可导出的实验数据。

精选案例只保留 6 个辨识度高、最适合评审理解的实验：规则不是视频、稳定结构、周期之美、局部规则产生移动、密度改变命运、复杂持续创造。评委点击任意瓷砖卡片一次，程序就会自动设置棋盘、图形、速度、种子或密度，清空旧曲线，切换到对应第 0 代并立即运行。“密度改变命运”会自动依次比较稀疏、中等、拥挤三种随机初始条件，说明同一条公式在不同参数下可能得到不同结局。需要完整讲解时，演示模式仍会自动按 6 段展示约 3 分钟精华流程。图形和场景选择后会立即更新棋盘，避免观众误以为选择没有生效。运行时，程序会用简单中文解释当前画面，例如“已经稳定”“周期重复”“持续变化”，并明确说明这些状态来自数学公式逐代计算。

为了避免现场操作混乱，界面把运行状态明确分成“运行中”“已暂停”“已停止：第 0 代”和“空棋盘”。开始/暂停只负责继续或暂停当前计算；停止/重置会保留当前实验参数并回到第 0 代；清空会进入明确的空棋盘状态，不会自动塞入旧图形。修改棋盘、图形、种子或密度时，程序会立即停止旧运行并加载新的第 0 代；点击案例或场景会立即切换并自动运行。

## 创新点

- 将数学规则、工程实现和实验数据记录放在同一个互动程序中。
- 随机初始状态由种子和密度共同决定，便于复现实验结果。
- 内置典型图形，能直接比较稳定、振荡和迁移三类现象。
- 页面打开后自动运行代表性案例，并用首次演示引导降低评委进入门槛。
- 标题旁提供全局演示入口，关闭引导后仍能通过动画提示快速找到。
- 主画布优先放大，实时数据证明放在精选案例下方，把“看起来在变”和“数据确实在变”都保留在评审视野里。
- 精选案例瓷砖把稳定、周期、移动、密度差异和复杂长期变化集中成一键实验，并同步显示当前案例参数，降低现场操作成本。
- 展板式讲解横幅同步展示公式、变量和观察结论，让评委快速理解数学意义。
- KaTeX 公式卡把生命游戏讲成“算子生成图像”，从 \(X_{t+1}=T(X_t)\) 解释每一帧为什么是实时计算结果。
- 同一说明同时提供小学生版、公式版、算子版和局部博弈版，降低理解门槛，也保留数学深度。
- 演示模式把关键实验组织成约 3 分钟精华流程，适合需要完整讲解时使用。
- 实时统计出生数和死亡数，让观察不只停留在动画效果，也能形成可分析的数据。
- CSV 导出可作为研究记录，支撑后续撰写报告或制作展示视频。

建议提交前至少保留三组实验数据：

| 实验 | 初始条件 | 观察目标 | 记录方式 |
| --- | --- | --- | --- |
| 稳定性实验 | 放置 `block`，运行 20 代 | 活细胞数量是否保持不变 | 截图与 CSV |
| 周期实验 | 放置 `blinker` 或 `pulsar` | 图形是否按固定周期恢复 | 截图与 CSV |
| 密度实验 | 使用同一种子，比较 15%、26%、40% 初始密度 | 活细胞数量曲线差异 | CSV 折线图 |
| 长期变化实验 | 选择“长期变化”场景 | 是否持续出现出生和死亡 | 截图、CSV 与短视频 |

实际提交时，应使用程序导出的真实 CSV 数据补充表格，并选择代表性截图或 3 分钟以内视频展示运行过程。
