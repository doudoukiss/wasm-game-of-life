# 生命演化数学游戏作品说明

## 创意来源

本作品来源于康威生命游戏，但展示目标不是做一个研究式可视化工具，而是做成打开就能玩的互动教学游戏。画布是一张生命棋盘，可以像玩游戏一样选择关卡、选择投放道具、点击棋盘改变系统，然后观察整个生命图像如何继续演化。

这个设计想回答一个直观问题：如果每个小格子只会做非常简单的判断，很多小格子放在一起，会不会长出复杂、有节奏、会移动、甚至长期变化的图像？作品让一次点击变成一次数学扰动：把一个图形投放进系统，再看它怎样改变后续结果，从而自然理解“这不是视频，而是实时数学计算”。

## 教学游戏玩法

页面打开后直接进入默认关卡“滑翔机发射器”。不需要先读长说明，也不需要先找参数按钮。画布旁会提示：点击棋盘投放稳定小方块，观察规则机器如何重新计算。

基本玩法是：

1. 选择一个关卡，例如发射器、飞船赛道、脉冲星、密度三连。
2. 选择一个投放道具，例如稳定小方块、滑翔机、闪烁灯、飞船、单格。
3. 在棋盘上点击，把这个道具加入当前生命系统。
4. 暂停或继续运行，观察碰撞、消失、周期、移动或长期变化。
5. 阅读右侧“数学旁白”，理解刚刚点击改变了什么数学变量。

在游戏语言中，关卡提供一个有代表性的生命世界；投放道具相当于向这个世界加入一个局部扰动；右侧旁白负责解释这个扰动为什么会改变后续演化。

## 数学原理

棋盘可以看成一幅由 0 和 1 组成的图像。第 \(t\) 代图像记作 \(X_t\)，第 \(r,c\) 个格子的状态记作：

\[
x_t(r,c)\in\{0,1\}
\]

其中 1 表示有活细胞，0 表示暂时没有细胞。每个格子先计算周围 8 个邻居中有多少活细胞：

\[
n_t(r,c)=\sum_{i=-1}^{1}\sum_{j=-1}^{1}x_t(r+i,c+j)-x_t(r,c)
\]

然后执行生命游戏规则：

- 活细胞邻居少于 2 个时消失，表示太孤单。
- 活细胞邻居为 2 或 3 个时继续存活。
- 空格邻居正好为 3 个时出现新细胞。
- 活细胞邻居多于 3 个时消失，表示太拥挤。

简单说法是：每个小格子每一轮只看身边 8 个朋友。朋友太少会孤单，朋友太多会拥挤，刚好合适就能留下；空格子如果周围正好有 3 个朋友，就会出现新细胞。所有格子同时判断，所以不会出现“先动的格子影响后动的格子”的问题。

用算子语言表达，生命游戏是一台规则机器 \(T\)：

\[
X_{t+1}=T(X_t),\qquad X_t=T^t(X_0)
\]

点击棋盘时，系统不是切换视频，而是把投放图形 \(P\) 加入当前图像，形成扰动后的图像：

\[
X'_t=X_t+P
\]

之后程序继续计算：

\[
X_{t+1}=T(X'_t)
\]

这就是本作品的核心教学价值：每一次点击都会改变数学系统本身，后续图像由同一条规则实时重新计算。

不同关卡对应不同数学现象：

| 游戏现象 | 数学表达 | 直观解释 |
| --- | --- | --- |
| 稳定小方块 | \(T(X)=X\) | 继续计算也不变，叫固定点。 |
| 闪烁灯、脉冲星 | \(T^k(X)=X\) | 图像一直变化，但每隔几代回到原样。 |
| 滑翔机、飞船 | 多次计算后形状平移 | 代码没有写“向前飞”，移动从局部规则中涌现。 |
| 密度三连 | 同一 \(T\)，不同 \(X_0\) | 起点不同，活细胞曲线和结局不同。 |
| 发射器、橡果 | 长期存在出现和消失 | 系统不会快速稳定，简单规则能持续创造结构。 |

## 实现过程

核心计算使用 Rust 编写，并通过 WebAssembly 在浏览器中运行。Rust 负责保存棋盘状态、执行生命游戏规则、放置典型图形、生成可复现随机初始状态，并输出代数、活细胞、出现和消失等统计数据。浏览器端使用 Vite、Canvas 和 JavaScript 负责游戏界面、关卡选择、投放道具、右侧数学旁白、生命数据曲线和 CSV 导出。

前端界面按“教学游戏”重新组织：

- 首屏不弹阻塞说明框，默认直接运行“滑翔机发射器”关卡。
- 画布是最大视觉中心，第一眼就能看到动态生命系统。
- 画布顶部提供“动态岛”式投放道具栏，按钮直接用生命图形本身表示小方块、滑翔机、闪烁灯、飞船和单格。
- 画布上方的操作台把关卡、运行控制和紧凑生命数据放在一起，形成 `1 选道具 -> 2 选关卡 -> 3 点画布` 的游戏流程。
- 鼠标移入棋盘时会出现当前道具的半透明预览，例如稳定小方块显示为 2 x 2 形状，滑翔机会显示 5 个细胞的形状。
- 点击棋盘后会出现短暂琥珀色脉冲和“实时扰动 / 新起点”提示，立刻显示系统已经被改变。
- 右侧先显示更醒目的生命数据，再显示“正在发生什么”的数学旁白。
- 数学旁白压缩成三段：现在发生什么、规则怎样算、接下来观察。规则段用 `n<2`、`n=2`、`n=3`、`n>3` 分类讨论，说明不同道具会改变局部邻居数。
- 生命数据增加趋势标签，例如“正在扩张”“趋于稳定”“周期重复”“持续变化”，帮助快速读懂曲线。
- 下方新增更完整的“进阶自定义”设置区，再保留完整玩法与规则说明和进阶公式，供深读和写报告使用。

状态机也按游戏操作重新整理：开始/暂停只控制当前计算；停止/重置回到最近一次投放后的起点；恢复本关清除扰动并回到关卡原始配置；清空会得到明确的空棋盘；随机会用当前种子和密度生成新的第 0 代。

## 关卡与道具设计

关卡不再是分散的“实验选项”，而是教学游戏中的关卡入口。动画冲击力强、最能体现数学规律的关卡排在前面：

- 滑翔机发射器：持续产生新结构。
- 长期变化：发射器、橡果、飞船同屏碰撞。
- 飞船赛道：轻型、中型、重型飞船并排移动。
- 滑翔机移动：5 个细胞产生整体迁移。
- 脉冲星花瓣：周期 3 的大振子。
- 多振子剧场：多个周期图形同屏比较。
- 密度三连：稀疏、中等、拥挤自动对比。
- 橡果长跑：小起点引发长期复杂变化。
- 图形花园：稳定、周期、移动同屏。
- 稳定小方块：固定点。

投放道具负责把观看变成参与：

- 稳定小方块：像障碍物，适合放在发射器或飞船路径上观察碰撞。
- 滑翔机：像移动粒子，适合扰动周期图形或稳定结构。
- 闪烁灯：像节奏器，适合展示周期扰动。
- 飞船：像较大的移动结构，适合观察整体迁移。
- 单格：像像素笔，适合解释孤立点为什么下一代会消失。

如果只放一个孤立单格，下一代它可能消失。这不是点击失效，而是因为它周围邻居数 \(n=0\)，满足 \(n<2\) 的消失条件，反而能证明程序真的在运行数学规则。

## 创新点

- 将康威生命游戏包装成“可玩的数学教学游戏”，降低上手门槛。
- 把“观看动画”改成“点击投放 -> 实时扰动 -> 继续演化”的参与式体验。
- 通过悬停预览和点击脉冲，把“我正在投放一个数学图形”变成可见反馈，而不是只在文字里解释。
- 区分运行中投放和暂停投放：运行中是改变当前图像 \(X_t\)，暂停或停止时是改变新的起点 \(X_0\)。
- 右侧生命数据和数学旁白同步解释当前操作，边玩边理解算子、邻域计数和动态系统。
- 动态岛道具栏把投放工具做成图形按钮，降低“按钮文字”和“画布图形”之间的理解成本。
- 关卡与道具融合：每个代表性场景都有推荐投放任务，而不是自己猜参数。
- 用 `停止/重置` 和 `恢复本关` 区分“回到扰动起点”和“回到原关卡”，避免现场操作混乱。
- 保留正式数学深度：固定点、周期轨道、涌现、初始条件敏感性、非快速收敛都能在下方说明中找到对应解释。
- 生命数据来自真实计算，可以导出 CSV 支撑作品报告。

## 玩法演示与视频脚本

内置玩法演示不再只是自动翻页展示结果，而是模拟完整玩法路径：

1. 进入发射器关卡，看持续产生滑翔机。
2. 自动投放稳定小方块，观察碰撞和改道。
3. 切换周期关卡，投放滑翔机，观察周期被扰动。
4. 切换移动关卡，暂停到关键状态，阅读右侧旁白。
5. 切换密度关卡，对比稀疏、中等、拥挤。
6. 进入长期变化关卡，说明简单规则可以长期创造结构。

后续录制 3 分钟以内 MP4 时，也应按这个玩法录屏：展示选择关卡、投放道具、暂停观察和阅读旁白，而不是只播放结果。
