# 生命演化数学实验室

这是一个面向 2026 年海淀区“海π”数学节“数学工程创意实践类”的互动小程序。项目用 Rust 实现康威生命游戏的核心演化规则，通过 WebAssembly 在浏览器中运行，并提供可视化棋盘、图形模板、实时统计和 CSV 数据导出。作品把生命游戏解释为“算子生成图像”的数学实验：每一帧都不是视频，而是同一个算子 `T` 对整张 0/1 图像 `X_t` 动态计算一次。

## 作品定位

- 作品类别：数学工程创意实践类
- 作品形式：数学软件 / 互动小程序
- 核心问题：简单局部规则如何通过反复迭代产生稳定、周期、迁移和复杂演化现象
- 数学内容：离散网格、邻域计数、算子迭代、比例统计、周期观察、数据记录与分析

## 功能

- 页面打开后自动运行“滑翔机发射器”动画代表性案例，让评委第一眼看到规则持续创造新结构
- 首次打开不弹阻塞说明框，画布旁直接提示“点画布注入图形”，让评委马上上手玩
- 面向评委的 Show Mode / 演示模式：按“选场景 -> 注入图形 -> 暂停观察 -> 读解释”的玩法脚本自动演示
- 右侧提供动态中文解说，优先用六年级能理解的“规则机器 T”解释当前实验
- 右侧和下方说明直接解释 `先数 n`、`n < 2`、`n = 2`、`n = 3`、`n > 3` 和 `下一张图 = T(这一张图)`
- 页面底部提供默认展开的长篇文档式说明，并在进阶区用 KaTeX 展示完整算子公式
- 主视觉区优先放大演化画布，实时数据证明压缩在右侧，辅助展示代数、活细胞、出生/死亡和曲线
- 画布边缘新增场景条、注入图形按钮组和运行工具栏，评委可以按当前场景推荐向棋盘注入稳定障碍物、滑翔机或周期扰动
- 手动画布会保存成新的第 0 代；运行中点击棋盘会实时注入元素并继续计算，证明画面不是预渲染视频
- 提供约 20 个紧凑一键实验场景，动画丰富案例排在前面，评委点击一次即可进入场景并获得推荐注入任务
- 128 x 128 默认生命游戏宇宙，并支持 48、64、96、128 等演示尺寸
- 内置稳定图形、振荡图形、滑翔机、轻型/中型/重型飞船、橡果和滑翔机发射器等典型图形
- 提供稀疏种子、中等密度、拥挤开始、飞船家族、图形花园、长期变化等实验场景
- 注入图形下拉框只改变下一次画布点击要加入的工具；实验场景选择后会立即更新棋盘
- 可设置随机种子和初始密度，保证实验可复现
- 开始、暂停、继续、停止/重置、清空、恢复本案例的状态语义清晰；修改棋盘、种子或密度会立即加载新的第 0 代
- 实时显示代数、活细胞数量、活细胞占比、出生数和死亡数
- 绘制活细胞数量变化曲线
- 用小学生能理解的中文实时解释当前画面是在运行“数邻居 -> 套公式 -> 生成下一代”的数学计算，而不是播放视频
- 导出 CSV 数据，用于作品说明中的实验记录

## 推荐评审流程

打开程序后会自动运行“滑翔机发射器”场景，评委不需要先读说明。先看大画布，再按画布旁提示点击棋盘，默认会注入稳定小方块；程序会把注入元素加入当前图像 \(X_t\)，从扰动后的 \(X'_t\) 继续计算 \(X_{t+1}=T(X'_t)\)。之后可以沿着画布边缘切换实验场景、切换注入图形、暂停到关键状态，并阅读右侧动态解说。`停止/重置` 会回到扰动后的起点，`恢复本案例` 会清除扰动回到原场景。最后可阅读底部长文档、调整高级参数并导出 CSV。

## 本地运行

安装 Node.js、npm 和 Rust 后，在项目根目录运行：

```bash
npm install
npm run dev
```

`npm run dev` 会先执行 `npm run build:wasm`，把 Rust 编译为浏览器可加载的 WASM 包，然后启动 Vite 开发服务器。

如果本机没有可用的 `wasm-pack`，可以使用项目依赖提供的版本：

```bash
npm install
```

也可以手动安装：

```bash
cargo install wasm-pack
```

## 构建

```bash
npm run build
npm run preview
```

生产构建输出在 `dist/`，WASM 中间产物输出在 `pkg/`。

## 验证

```bash
cargo test
cargo build --target wasm32-unknown-unknown
npm run build
```
