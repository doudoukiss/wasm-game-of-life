# 生命演化数学实验室

这是一个面向 2026 年海淀区“海π”数学节“数学工程创意实践类”的互动小程序。项目用 Rust 实现康威生命游戏的核心演化规则，通过 WebAssembly 在浏览器中运行，并提供可视化棋盘、图形模板、实时统计和 CSV 数据导出。作品把生命游戏解释为“算子生成图像”的数学实验：每一帧都不是视频，而是同一个算子 `T` 对整张 0/1 图像 `X_t` 动态计算一次。

## 作品定位

- 作品类别：数学工程创意实践类
- 作品形式：数学软件 / 互动小程序
- 核心问题：简单局部规则如何通过反复迭代产生稳定、周期、迁移和复杂演化现象
- 数学内容：离散网格、邻域计数、算子迭代、比例统计、周期观察、数据记录与分析

## 功能

- 页面打开后自动运行“规则不是视频”精选案例，让评委不需要摸索就能看到公式逐代计算
- 首次打开会弹出演示引导框，鼓励评委先看 3 分钟 Show Mode；标题旁始终保留醒目的 `开始演示` 按钮
- 面向评委的 Show Mode / 演示模式：自动按 6 段、约 3 分钟精华实验讲解规则、初始条件、算法逻辑和结果
- 画布上方提供展板式实时讲解横幅，突出主结论、公式 B3/S23、变量 n/state/t 和结果意义
- 新增 KaTeX 公式卡，展示 `x_t(r,c)`、邻居数 `n_t(r,c)`、`X_{t+1}=T(X_t)` 和 `X_t=T^t(X_0)`
- 新增“数学算子说明”区，用小学生版、公式版、算子版和局部博弈版解释每一帧怎样被动态计算出来
- 主视觉区优先放大演化画布，实时数据证明放在精选案例下方，辅助展示代数、活细胞、出生/死亡和曲线
- 提供 6 个一键精选案例瓷砖和当前案例参数摘要，评委点击一次即可切换并自动运行
- 128 x 128 默认生命游戏宇宙，并支持 48、64、96、128 等演示尺寸
- 内置稳定图形、振荡图形、滑翔机、轻型/中型/重型飞船、橡果和滑翔机发射器等典型图形
- 提供稀疏种子、中等密度、拥挤开始、飞船家族、图形花园、长期变化等实验场景
- 图形和实验场景选择后会立即更新棋盘，方便评委直接比较差异
- 可设置随机种子和初始密度，保证实验可复现
- 开始、暂停、继续、停止/重置、清空的状态语义清晰；修改参数会立即加载新的第 0 代
- 实时显示代数、活细胞数量、活细胞占比、出生数和死亡数
- 绘制活细胞数量变化曲线
- 用小学生能理解的中文实时解释当前画面是在运行“数邻居 -> 套公式 -> 生成下一代”的数学计算，而不是播放视频
- 导出 CSV 数据，用于作品说明中的实验记录

## 推荐评审流程

打开程序后会自动运行“规则不是视频”案例，并弹出演示引导框，建议评委先点击 `开始演示` 观看约 3 分钟精华流程。若暂不演示，标题旁的 `开始演示` 按钮会被短暂强调，方便评委随时重新开始。主视觉区优先展示最大画布，让评委先看到三格细胞如何由 `B3/S23` 公式计算出周期变化；画布下方的公式卡说明 `X_{t+1}=T(X_t)`，帮助评委理解每一帧都是算子计算结果。右侧可点击 6 个精选案例瓷砖快速复查，瓷砖下方的实时数据证明会同步显示代数、活细胞、占比、出生、死亡和曲线。最后可自由探索并导出 CSV。

## 本地运行

安装 Node.js、npm 和 Rust 后，在项目根目录运行：

```bash
npm install
npm run dev
```

`npm run dev` 会先执行 `npm run build:wasm`，把 Rust 编译为浏览器可加载的 WASM 包，然后启动 Vite 开发服务器。

如果本机没有可用的 `wasm-pack`，可以使用项目依赖提供的版本：

```bash
npm install
```

也可以手动安装：

```bash
cargo install wasm-pack
```

## 构建

```bash
npm run build
npm run preview
```

生产构建输出在 `dist/`，WASM 中间产物输出在 `pkg/`。

## 验证

```bash
cargo test
cargo build --target wasm32-unknown-unknown
npm run build
```
