# 生命演化数学实验室

这是一个面向 2026 年海淀区“海π”数学节“数学工程创意实践类”的互动小程序。项目用 Rust 实现康威生命游戏的核心演化规则，通过 WebAssembly 在浏览器中运行，并提供可视化棋盘、图形模板、实时统计和 CSV 数据导出。

## 作品定位

- 作品类别：数学工程创意实践类
- 作品形式：数学软件 / 互动小程序
- 核心问题：简单局部规则如何产生稳定、周期、迁移和复杂演化现象
- 数学内容：离散网格、邻域计数、比例统计、周期观察、数据记录与分析

## 功能

- 面向评委的 Show Mode / 演示模式：自动按 10 段代表性实验讲解规则、初始条件、算法逻辑和结果
- 画布上方提供醒目的实时讲解横幅，说明“现在看什么、数学规则、算法怎样算、深层原理”
- 提供案例导航 Tab：主要情况、稳定、周期、移动、复杂长期、随机密度，评委不用手动调参数也能快速复查重点
- 128 x 128 默认生命游戏宇宙，并支持 48、64、96、128 等演示尺寸
- 内置稳定图形、振荡图形、滑翔机、轻型/中型/重型飞船、橡果和滑翔机发射器等典型图形
- 提供稀疏种子、中等密度、拥挤开始、飞船家族、图形花园、长期变化等实验场景
- 图形和实验场景选择后会立即更新棋盘，方便评委直接比较差异
- 可设置随机种子和初始密度，保证实验可复现
- 实时显示代数、活细胞数量、活细胞占比、出生数和死亡数
- 绘制活细胞数量变化曲线
- 用小学生能理解的中文实时解释当前画面是在运行“数邻居 -> 套公式 -> 生成下一代”的数学计算，而不是播放视频
- 导出 CSV 数据，用于作品说明中的实验记录

## 推荐评审流程

打开程序后先点击 `开始演示`。演示模式会自动展示约 10 分钟的评审讲解：项目是什么、数学规则不是视频、稳定结构、多种周期图形、移动结构、飞船家族、不同初始密度、小起点长变化、非快速收敛和总结观察。每段都会同步显示当前初始条件、数学规则、算法逻辑、深层原理和预测/观察结果。看完演示后，再使用案例导航 Tab 快速复查主要情况，最后用图形、场景、随机和 CSV 导出功能自由探索。

## 本地运行

安装 Node.js、npm 和 Rust 后，在项目根目录运行：

```bash
npm install
npm run dev
```

`npm run dev` 会先执行 `npm run build:wasm`，把 Rust 编译为浏览器可加载的 WASM 包，然后启动 Vite 开发服务器。

如果本机没有可用的 `wasm-pack`，可以使用项目依赖提供的版本：

```bash
npm install
```

也可以手动安装：

```bash
cargo install wasm-pack
```

## 构建

```bash
npm run build
npm run preview
```

生产构建输出在 `dist/`，WASM 中间产物输出在 `pkg/`。

## 验证

```bash
cargo test
cargo build --target wasm32-unknown-unknown
npm run build
```
