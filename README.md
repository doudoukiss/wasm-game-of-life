# 生命演化数学游戏

一个可以被实时干预的规则机器。这个项目面向 2026 年海淀区“海π”数学节“数学工程创意实践类”，用 Rust/WASM 实现康威生命游戏规则，并把它设计成打开就能玩的互动教学游戏：选择关卡，选择投放图形，点击棋盘改变系统，再观察每一代如何由同一条数学规则重新计算。

## 作品定位

- 作品类别：数学工程创意实践类
- 作品形式：互动教学游戏 / 数学软件
- 核心体验：像玩游戏一样投放道具，亲手扰动一个实时数学系统
- 数学内容：离散网格、邻域计数、算子迭代、固定点、周期轨道、涌现、初始条件敏感性

## 游戏玩法

1. 打开页面后，默认关卡“滑翔机发射器”会自动运行。
2. 先看大画布，再按提示点击棋盘，默认会投放“稳定小方块”。
3. 这次点击不是画装饰，而是把一个图形加入当前图像 `X_t`，得到扰动后的 `X'_t`。
4. 程序继续计算 `X_{t+1}=T(X'_t)`，所以后续轨迹会被你的点击改变。
5. 你可以切换关卡、切换投放图形、暂停观察关键状态，并阅读右侧“数学旁白”。

这个流程不需要先阅读长说明，就能自然理解：画面不是预渲染动画，而是一个可被实时干预的数学动态系统。

## 功能

- 首屏直接运行动画强烈的“滑翔机发射器”关卡，画布是第一视觉中心。
- 投放工具变成画布顶部的“动态岛”道具栏，用小格子图形直接表示稳定小方块、滑翔机、闪烁灯、飞船和单格。
- 关卡选择、运行控制和紧凑生命数据组成首屏操作台，常用操作不需要滚动寻找。
- 关卡墙提供约 20 个代表性场景，动画丰富、最容易看懂的关卡排在前面。
- 常用投放道具集中在画布顶部道具栏；更多复杂图形通过关卡、场景和居中投放组合使用。
- 鼠标移入棋盘时会显示当前道具的半透明预览，提前看到点击会投放什么形状。
- 点击棋盘后会出现琥珀色脉冲和“实时扰动 / 新起点”反馈，明确说明这次点击已经改变系统。
- 点击关卡一次即可加载、同步推荐道具并自动运行。
- 运行中点击棋盘会实时投放图形；暂停或停止时点击棋盘会改变第 0 代起点。
- `停止/重置` 回到最近一次投放后的起点，`恢复本关` 清除扰动并回到关卡原始配置。
- 右侧顶部是紧凑的“进阶自定义”，改棋盘、种子、密度和速度时仍能看见画布。
- 进阶参数重建起点后，默认投放道具会回到“稳定小方块 / 障碍块”，方便继续做碰撞和扰动实验；单独调速度只改变节奏，不改变当前道具。
- 右侧信息顺序为“进阶自定义 -> 生命数据曲线 -> 互动证明 / 数学旁白”，先调参数，再看曲线，最后读解释。
- “互动证明 / 数学旁白”用分类讨论说明 `n=0或1`、`n=2`、`n=3`、`n=4到8`，并解释投放道具会改变局部邻居数 `n`。
- 右侧“生命数据”只保留活细胞曲线和趋势标签，数值指标放在关卡控制区，避免重复。
- 参数变化和道具投放会以画布弹幕反馈，直接说明改变的是 `X_0`、`X_t` 还是局部邻居数 `n`。
- 画布正下方默认展开“看懂演化”说明，用 CSS 小棋盘和微动画展示固定点、周期、移动、长期变化和起点敏感性。
- 页面底部保留“玩法与规则说明”，先用简单语言解释规则，再给出正式算子公式，避免和画布下方说明重复。
- 玩法演示压缩为约 2 分钟高密度流程，优先展示发射器碰撞、飞船移动、脉冲星扰动、密度切换和长期变化。
- 进阶自定义保留棋盘、随机种子、密度、速度、重开起点、居中投放和导出曲线 CSV，作为复杂定制和报告记录工具。

## 推荐玩法流程

打开页面后先直接玩画布：在发射器路径上点击一次，观察稳定小方块如何改变后续碰撞；再看画布正下方的“看懂演化”，理解道具和关卡为什么会这样变化。然后切换“飞船赛道”“脉冲星花瓣”“密度三连”“橡果长跑”等关卡，继续投放不同道具。需要快速总览时，点击标题旁的“玩法演示”。需要完整解释时，阅读底部“玩法与规则说明”。

## 本地运行

安装 Node.js、npm 和 Rust 后，在项目根目录运行：

```bash
npm install
npm run dev
```

`npm run dev` 会先执行 `npm run build:wasm`，把 Rust 编译为浏览器可加载的 WASM 包，然后启动 Vite 开发服务器。

如果本机没有可用的 `wasm-pack`，项目依赖会提供本地版本；也可以手动安装：

```bash
cargo install wasm-pack
```

## 构建

```bash
npm run build
npm run preview
```

生产构建输出在 `dist/`，WASM 中间产物输出在 `pkg/`。

## 验证

```bash
node --check www/main.js
cargo test
cargo build --target wasm32-unknown-unknown
npm run build
```
